                    MODUS VAGUE THEME FOR GNU EMACS
                   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


This is the emacs port of the [vague] theme built on top of [Modus
themes].

As described in the primary vague theme repo:

      A cool, dark, low contrast colorscheme. Pastel yet vivid,
      like a fleeting memory…

*Note:*

I ported this theme for emacs for personal use. As such, the current
state of the theme serves most of my needs.

Since it builds up on Modus themes, most of the font-faces should
work. If not, please open an issue on the issue tracker.


[vague] <https://github.com/vague-theme/vague>

[Modus themes] <https://protesilaos.com/emacs/modus-themes>

2 Installation
══════════════

2.1 Release version
───────────────────

  The release version of the package is available on GNU ELPA.  Simply
  run `M-x package-install RET modus-vague RET'.


2.2 Development version
───────────────────────

  If you need more up-to-date version of the package, install via
  `package-vc':


2.2.1 With `use-package' and `package.el'
╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌

  ┌────
  │ (use-package modus-vague
  │   :vc (:url "https://github.com/paniash/modus-vague"
  │        :rev :newest
  │        :branch "main")
  │   :config
  │   (modus-themes-load-theme 'modus-vague))
  └────


2.2.2 With `use-package' and `straight.el'
╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌

  ┌────
  │ (use-package modus-vague
  │   :straight (modus-vague :host github
  │                          :repo "paniash/modus-vague"
  │                          :branch "main")
  │   :config
  │   (modus-themes-load-theme 'modus-vague))
  └────


2.2.3 Manual Installation
╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌

  • Clone the git repository into a directory (say
    `~/.emacs.d/themes/'):

  ┌────
  │ git clone https://github.com/paniash/modus-vague ~/.emacs.d/themes/modus-vague
  └────

  • Add the following to your `init.el':

  ┌────
  │ (add-to-list 'custom-theme-load-path "~/.emacs.d/themes/modus-vague")
  │ (load-theme 'modus-vague t)
  └────


  Since this theme builds on top of modus themes, one can use the same
  customization options that modus themes provide.
