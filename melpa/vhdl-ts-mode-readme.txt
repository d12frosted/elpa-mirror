Major mode to navigate and edit VHDL files with tree-sitter.

Provides tree-sitter based implementations for the following features:
- Syntax highlighting
- Indentation
- `imenu'
- `'which-func'
- Navigation functions
- Completion at point

Package info:
 - https://github.com/gmlarumbe/vhdl-ext#tree-sitter

Setup instructions:
 - https://github.com/gmlarumbe/vhdl-ext/wiki/Tree-sitter
