Gnosis combines linked Org notes with spaced repetition and self-testing.
Notes (nodes) remain plain Org files.  SQLite stores their index,
questions (themata), schedules and review history.

Write notes with `gnosis-nodes-find', create questions with
`gnosis-add-thema', and link them to their sources using
`gnosis-nodes-insert'.  Use `gnosis-review' for scheduled review or
`gnosis-review-topic' to study questions linked to a note.  Separate
practice sessions leave spaced-repetition schedules unchanged.

Scheduling uses FSRS-6.  Optional agent interfaces support content
discovery, guarded organization, native practice and rubric-based
response evaluation.  Ordinary use requires no model or service.
